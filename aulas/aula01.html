1eventos = ler_csv("eventos_desdobramento.csv", parse_dates=["data"])2 3def preco_negociado(fechamento, eventos, ticker):4    """Close multiplicado pelos fatores dos eventos posteriores a cada data."""5    serie = fechamento[ticker].dropna()6    fator = np.ones(len(serie))7    do_ticker = eventos[eventos["ticker"] == ticker]8    for data, f in zip(do_ticker["data"], do_ticker["fator"]):9        fator = fator * np.where(serie.index < data, f, 1.0)10    return serie * fator

Revisão de código do coletar

Manter

  1. linha 1 Parametrizada

    def coletar(tickers, inicio, fim):

    Tickers e datas entram como argumento; a cesta do grupo não exige editar a função.

  2. linha 11 Corrige o fim exclusivo

    fim_exclusivo = pd.Timestamp(fim) + pd.Timedelta(days=1)

    O último pregão pedido vem na tabela, e o motivo está no nome da variável.

  3. linha 16 Escolha de preço explícita

    auto_adjust=False,

    Close e Adj Close chegam separados; quem chama decide qual usar.

  4. linha 26 Origem devolvida

    return fechamento, ajustado, "yfinance, ao vivo"

    Quem chama sabe se os números vieram da rede ou do snapshot.

Revisar antes do A1

  1. linha 27 Captura ampla demais

    except Exception as erro:

    Pega também erro de programação, como uma mudança no formato do yfinance, e cai no snapshot sem aviso. Capturar só erros de rede.

  2. linha 22 Falha parcial passa

    if not bruto.empty:

    Ticker sem dado vira coluna vazia, e a tabela não fica vazia. Conferir colunas inteiras sem dado.

  3. linha 28 Mensagem curta

    print("coleta ao vivo falhou, seguindo com o snapshot:",

    Só o tipo do erro aparece. Usar warnings com a mensagem completa.

  4. linha 16 Adj Close muda com o tempo

    auto_adjust=False,

    Cada provento novo reajusta o passado: a mesma chamada, em outro dia, devolve outros números. Registrar a data da coleta em ADR.
