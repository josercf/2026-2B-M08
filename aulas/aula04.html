Pesos, retorno e risco em forma vetorial

Uma carteira é um vetor de pesos que soma 1

Pesos iguais rendem 8,34%, abaixo do CDI

# mu: retorno esperado anual (15)
# cov: covariância anual (15 x 15)
# rf: CDI anualizado na janela
def metricas(w, mu, cov, rf):
    retorno = w @ mu
    volatilidade = np.sqrt(w @ cov @ w)
    sharpe = (retorno - rf) / volatilidade
    return retorno, volatilidade, sharpe

w = np.full(15, 1 / 15)
metricas(w, mu, cov, rf)
Retornow · μ, a média dos retornos ponderada pelos pesos
VariânciawT Σ w, que soma cada covariância ponderada pelo par de pesos
Sharpe(retorno - CDI) / volatilidade: prêmio sobre o CDI por unidade de risco

O motor sorteia 10.000 carteiras em menos de 1 s

def sortear(n, mu, cov, rf, semente=42):
    gerador = np.random.default_rng(semente)
    pesos = gerador.random((n, len(mu)))
    pesos /= pesos.sum(axis=1, keepdims=True)
    retorno = pesos @ mu
    volatilidade = np.sqrt(np.einsum(
        "ij,jk,ik->i", pesos, cov, pesos))
    sharpe = (retorno - rf) / volatilidade
    return pesos, retorno, volatilidade, sharpe

pesos, ret, vol, sharpe = sortear(
    10_000, mu, cov, rf)

Otimização com restrições

Função objetivo, soma 1 e nenhum peso negativo

Otimização com SLSQP no SciPy

from scipy.optimize import minimize

n = len(mu)
soma_1 = {"type": "eq",
          "fun": lambda w: w.sum() - 1}
limites = [(0, 1)] * n  # sem venda a descoberto
inicio = np.full(n, 1 / n)

def menos_sharpe(w):
    return -(w @ mu - rf) / np.sqrt(w @ cov @ w)

ms = minimize(menos_sharpe, inicio, method="SLSQP",
              bounds=limites, constraints=[soma_1])
mv = minimize(lambda w: w @ cov @ w, inicio,
              method="SLSQP", bounds=limites,
              constraints=[soma_1])
Objetivoo que se minimiza: a variância, ou o Sharpe com sinal trocado
