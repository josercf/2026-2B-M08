FastAPI ao vivo

Rota por operação de negócio, Pydantic e /docs

A rota importa o otimizador das sprints

from carteira import dados, pipeline

class PedidoCarteira(BaseModel):
    tickers: list[str] = Field(min_length=2,
                               max_length=15)
    inicio: date = date(2019, 1, 1)
    fim: date = date(2026, 8, 31)
    # + taxa opcional e validador de repetição

@lru_cache(maxsize=64)
def _calcular(tickers, inicio, fim, rf):
    try:
        return Resultado(**pipeline.calcular(
            tickers, inicio, fim, rf))
    except dados.TickerDesconhecido as erro:
        raise HTTPException(404, "Ticker fora ...")

@app.post("/carteiras/otimizar")
def otimizar(pedido: PedidoCarteira) -> Resultado:
    return _calcular(tuple(pedido.tickers), ...)

Erros do contrato da API

Que erro a API deve devolver para um ticker que não existe: 404, recurso fora da base, ou 422, entrada inválida? Cada dupla escolhe e justifica pelo contrato antes de revelar.

StatusQuem detectaExemploO que o gestor lê
422Pydantic, antes do cálculoum ticker só; início depois do fimescolha ao menos dois ativos e um período válido
404o coletor, ao procurar o tickerXPTO3algum ativo não está na base (XPTO3)
503a rota de interpretaçãoservidor sem OPENROUTER_API_KEYos números da carteira continuam válidos
502a rota de interpretaçãoo provedor do LLM não respondeuos números da carteira continuam válidos

O exemplo adota 404 e registra a escolha no SPEC.md; 422 também é defensável, desde que o contrato diga qual e mantenha o mesmo corpo de erro. Um 500 fica fora do contrato: é exceção sem tratamento, defeito do grupo.

O componente React

Estado, fetch, carregamento, erro e o gráfico

O componente guarda estado e delega o cálculo

const [carregando, setCarregando] = useState(false);
const [erro, setErro] = useState(null);
const [resultado, setResultado] = useState(null);

async function aoOtimizar(evento) {
  evento.preventDefault();
  setCarregando(true);
  setErro(null);
  try {
    setResultado(await otimizar(pedido()));
  } catch (e) {
    setResultado(null);
    setErro(e.message);   // já traduzida em api.js
  } finally {
    setCarregando(false);
  }
}
useStatecada mudança de estado redesenha a tela
api.jstodo o fetch num arquivo; 404 vira "algum ativo não está na base"
Carregandoo botão vira "Calculando..." e não aceita outro clique
CORSReact em localhost:5173, API em 127.0.0.1:8000: sem o middleware, o navegador descarta a resposta
